CRIMENET / CRIMENET AI

CRIMENET is a research project that aims to understand how organized crime works.

This page answers questions about organized crime by querying a knowledge graph on criminal organizations, all extracted from Wikipedia.

A large language model is connected directly to the graph, so it reasons from the evidence instead of inventing facts.

Like any AI, CRIMENET AI can make mistakes. You can double check any information on the dashboard and the network browser.
Nothing is saved. Copy anything you want to keep before you leave.
